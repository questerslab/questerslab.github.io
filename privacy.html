Privacy policy

Last updated: 18 November 2026

Who this covers

This policy covers the Questers Lab website and Questers Lab Analytics, a private tool the Questers Lab channel owner uses to read their own YouTube channel's statistics. The tool is not offered to the public, and only the channel owner signs in to it.

What data the tool reads

  • With the owner's permission, it uses Google's read-only scopes youtube.readonly and yt-analytics.readonly through the YouTube API Services.
  • It reads the owner's own channel statistics (for example views, watch time, subscribers and traffic sources) and public information about public YouTube channels and videos.
  • It cannot upload, edit or delete anything, and it does not read data from any other Google account.

How the data is used and stored

  • The data is used only to write performance reports that help plan the channel's videos.
  • Reports are kept in the owner's private workspace. Nothing is sold, shared with third parties or used for advertising.
  • Sign-in tokens are stored as private secrets and are never published.

Website visitors

This website does not use cookies, analytics or trackers, and it does not collect personal data. It is hosted on GitHub Pages, which may keep standard server logs (see GitHub's privacy statement).

YouTube and Google

Questers Lab Analytics uses the YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. You can remove the tool's access at any time from your Google Account's third-party connections page.

Contact

Questions about this policy: send a message through the Questers Lab YouTube channel.
